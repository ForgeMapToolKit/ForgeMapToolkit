================================================================================
                    GITHUB UPLOAD GUIDE
================================================================================

SCHRITT 1: ERSTELLE EIN NEUES GITHUB REPOSITORY
------------------------------------------------

1. Gehe zu: https://github.com/new
2. Repository Name: z.B. "map-tool-suite"
3. Description: "Supreme Commander Map Tool Suite"
4. Wähle: Public oder Private
5. WICHTIG: NICHT "Initialize this repository with a README" ankreuzen
6. Klicke: "Create repository"

================================================================================

SCHRITT 2: ERSTELLE .gitignore DATEI
-------------------------------------

Erstelle eine Datei namens ".gitignore" im Projekt-Root mit folgendem Inhalt:

# Temporary files
*.tmp
*.temp
~*

================================================================================

SCHRITT 3: ÖFFNE CMD/TERMINAL IM PROJEKT-ORDNER
------------------------------------------------

Windows:
  1. Öffne den Projekt-Ordner im Explorer
  2. Klicke in die Adressleiste
  3. Tippe: cmd
  4. Drücke Enter

================================================================================

SCHRITT 4: INITIALISIERE GIT UND PUSHE
---------------------------------------

Führe diese Befehle nacheinander aus:

# 1. Git Repository initialisieren
git init

# 2. Alle Dateien hinzufügen
git add .

# 3. Ersten Commit erstellen
git commit -m "Initial commit: Map Tool Suite"

# 4. Branch auf main umbenennen
git branch -M main

# 5. Remote Repository hinzufügen
# ERSETZE "DEIN-USERNAME" und "DEIN-REPO-NAME" mit deinen Daten!
git remote add origin https://github.com/DEIN-USERNAME/DEIN-REPO-NAME.git

# 6. Zum GitHub pushen
git push -u origin main

================================================================================

BEISPIEL:
---------

Wenn dein GitHub Username "john123" ist und dein Repo "map-tool-suite":

git remote add origin https://github.com/john123/map-tool-suite.git
git push -u origin main

================================================================================

SCHRITT 5: AUTHENTIFIZIERUNG
-----------------------------

Beim ersten Push wirst du nach Zugangsdaten gefragt:

Option A - Personal Access Token (Empfohlen):
  1. Gehe zu: https://github.com/settings/tokens
  2. Klicke: "Generate new token" → "Generate new token (classic)"
  3. Note: "Map Tool Suite"
  4. Expiration: Wähle eine Dauer
  5. Scope: Wähle "repo" (alle Checkboxen unter repo)
  6. Klicke: "Generate token"
  7. KOPIERE DEN TOKEN (wird nur einmal angezeigt!)
  8. Beim git push:
     - Username: Dein GitHub Username
     - Password: Der generierte Token (nicht dein Passwort!)

Option B - GitHub CLI:
  1. Installiere GitHub CLI: https://cli.github.com/
  2. Führe aus: gh auth login
  3. Folge den Anweisungen

================================================================================

TROUBLESHOOTING:
----------------

Problem: "git: command not found"
Lösung: Git installieren von: https://git-scm.com/downloads

Problem: "fatal: remote origin already exists"
Lösung: git remote remove origin
        Dann Schritt 5 wiederholen

Problem: "Permission denied"
Lösung: Überprüfe Username und Token
        Token muss "repo" Berechtigung haben

Problem: "Updates were rejected"
Lösung: git pull origin main --allow-unrelated-histories
        git push -u origin main

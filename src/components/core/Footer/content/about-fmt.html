About ForgeMapToolkit

ForgeMapToolkit (FMT) is a desktop application for advanced Supreme Commander: Forged Alliance map creation. It doesn't cover terrain sculpting or basic texturing because the FAF Map Editor already does that well. FMT exists for the layer on top of that. Skyboxes, emitter-driven atmosphere, and realistic, large-scale prop placement. It's built for mappers who want to push a map's atmosphere to the next level, not for a first pass at a heightmap.

Origins

FMT didn't start as a toolkit. It started as a handful of small Python scripts used to generate wreckage placements with attached emitters that originally written to hand off to IndexLibrorum who needed the same thing. Handing over several fragmented scripts felt clunky, so they got consolidated into a single small Python program.

The look of that program never sat right, which led to a rewrite as an Electron app. From there it kept growing. One tool became several, several became tabs, and tabs kept getting added as new advanced mapping problems came up. FMT is currently at 15 tabs covering distinct areas of advanced mapping.

What FMT Focuses On

Everything in FMT targets the atmospheric and technical side of mapping. From skybox generation over to emitter placement and configuration, and automatic prop distribution using erosion simulation and Gaea-based terrain data for realistic scatter patterns. These are tools for cutting-edge, atmosphere-focused map work and not entry-level mapping tasks.

Building FMT's live skybox preview required more than FMT itself could provide. The FAF Map Editor was extended with ForgeBridgeServer.cs, a named-pipe bridge that syncs skybox changes between the editor and FMT in real time. A small example of FMT's development reaching back into the tools it works alongside.

FMT is still actively developed, with new tabs and tools added as new advanced mapping needs come up.

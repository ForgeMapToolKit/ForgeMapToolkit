Getting Started

  1. Open Settings and set your game paths. This includes the map editor path, your map folder, and the game's gamedata folder. FMT needs these to find your maps and read the game's assets.
  2. Click Scan Libraries. This reads through the game's archives to build the unit, emitter, and prop database FMT uses across its tools, so it can take a little while the first time.
  3. Once the scan is done, open whichever tab matches what you want to work on first and get started. There is no required order beyond this, the tabs are independent tools built around the same library.

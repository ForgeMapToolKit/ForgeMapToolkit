Documentation

Every tab in FMT has its own dedicated help, opened through a help button on that tab, marked with a help icon or the word "Help". The exact placement varies by tab, but it is always visible while you are working.

Opening it brings up that tool's help console, broken into sections such as Workflow, walking through exactly how the tool is meant to be used, step by step, rather than just listing what each setting does.

This means documentation lives next to the tool it explains instead of in one long combined manual. If you are looking for how a specific tool works, open that tab first and use its help button.

================================================================================
                    MAP TOOL SUITE - INSTALLATION
================================================================================

REQUIREMENTS:
-------------
- Windows 10 or later
- Node.js 16+ (Download from: https://nodejs.org/)

================================================================================

INSTALLATION STEPS:
-------------------

1. Install Node.js
   → Download from: https://nodejs.org/
   → Install the LTS (Long Term Support) version
   → Restart your computer after installation

2. Open Command Prompt in the project folder
   → Navigate to the project folder in File Explorer
   → Click in the address bar and type: cmd
   → Press Enter

3. Install dependencies
   → Type: npm install
   → Press Enter
   → Wait for installation to complete (may take 2-5 minutes)

4. Build the project
   → Type: npm run build
   → Press Enter
   → Wait for build to complete

5. Start the application
   → Type: npm run electron:dev
   → Press Enter
   → The application will start

================================================================================

QUICK START (After first installation):
----------------------------------------

1. Open CMD in project folder
2. Type: npm run electron:dev
3. Press Enter

================================================================================

TROUBLESHOOTING:
----------------

Problem: "npm is not recognized"
Solution: Node.js is not installed or not in PATH
         → Reinstall Node.js
         → Make sure to check "Add to PATH" during installation

Problem: "npm install" fails
Solution: → Check internet connection
         → Delete node_modules folder and try again
         → Run CMD as Administrator

Problem: Build fails
Solution: → Make sure npm install completed successfully
         → Check for error messages in the output
         → Try deleting node_modules and running npm install again

================================================================================

CREATING A SHORTCUT:
--------------------

For easier access, create a batch file:

1. Create a new text file in the project folder
2. Name it: start.bat
3. Open it with Notepad
4. Paste this content:

@echo off
cd /d "%~dp0"
npm run electron:dev
pause

5. Save and close
6. Double-click start.bat to run the application

================================================================================

FULL COMMANDS REFERENCE:
-------------------------

npm install              - Install all dependencies
npm run build           - Build the project
npm run electron:dev    - Start the application in development mode
npm run electron:build  - Create a distributable installer (if configured)
